# txt2dir
An interactive directory builder powered by fzf. Features a live file preview, robust line-by-line processing, and smart error handling for dynamic folder creation.

# Bash Folder Creator
A simple tool to automate folder creation using `fzf` and logging.

## Features
* **Create from File:** Reads a .txt file and makes folders from each line.
* **Dynamic Creation:** Type names directly to create folders.
* **Logging:** Tracks all actions in `activity.txt`.
* **Visuals:** Includes a smooth progress bar.

## How to Run
1. Make it executable: `chmod +x script_name.sh`
2. Run it: `./script_name.sh`

## Dependencies
* `fzf` (for the interactive menus)
